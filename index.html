Abstract · 한국어 요약

CraftGround: A Flexible Reinforcement Learning Environment Based on the Latest Minecraft

Journal / DOI ↗ 학회 원문 ↗ Code ↗

Minecraft 1.21 기반의 강화학습 환경 CraftGround를 소개합니다. 시각, 소리, 생물 군계, 게임 통계 등 여러 관측 정보와 유연한 실험 설정을 지원합니다. 나무 채취, 몬스터 회피, 낚시 과제에서 VPT, PPO, RecurrentPPO, DQN을 평가해 사전 학습 및 온라인 학습 에이전트의 특성과 환경 활용성을 살펴봅니다.
